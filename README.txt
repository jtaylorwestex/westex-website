# WesTex Roofing and Construction LLC website starter

This is a responsive, one-page website starter for Westexroofs.com.

## Included
- `index.html` — page content and structure
- `styles.css` — responsive navy/red/white styling
- `script.js` — mobile menu and estimate-request email draft
- `README.txt` — setup and publishing checklist

## Important setup before publishing
1. In `script.js`, replace `REPLACE-WITH-YOUR-EMAIL@example.com` with the business email address that should receive estimate requests. The current form opens the visitor's email app; it does not send submissions to a server by itself.
2. Replace the sample stock photos with your own completed project photos when available.
3. Confirm the services, service area, claims, and business details are accurate.
4. Add a privacy notice if you later connect analytics, tracking, or a hosted form service.
5. Test on a phone and desktop, submit a test estimate request, and check every phone and navigation link.

## Publishing options
You need a web hosting provider in addition to owning the domain. A simple static host can publish these three website files. Upload `index.html`, `styles.css`, and `script.js` to the host's site/public folder, then connect `westexroofs.com` using the host's domain instructions. DNS records vary by hosting provider; do not change nameservers or DNS records until you know where email and other domain services are managed.

## Find your registrar / DNS provider
Open https://lookup.icann.org/ and search `westexroofs.com`. Review Registrar Information and Nameservers. The registrar and DNS host can be different providers. Keep your existing email DNS records intact when connecting hosting.
